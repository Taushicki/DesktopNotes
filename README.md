# DesktopNotes

Локальные стикеры для Windows 10 22H2 / Windows 11 (x64). C# / .NET 10, WPF, MVVM. Поддерживаются группы, закрепление, прилипание и визуальные связи.

## Запуск

Распакуйте **всю** папку `artifacts/win-x64` или архив `artifacts/DesktopNotes-win-x64.zip` в постоянное место и запустите `DesktopNotes.exe`. Автономная сборка включает .NET: установка runtime и права администратора не нужны. Приложение не подписано цифровым сертификатом.

При первом запуске появляются стикер и настройки. Нажмите «Добавить пункт меню»: затем правый клик по пустому месту рабочего стола → «Создать заметку». В Windows 11 сначала выберите «Показать дополнительные параметры». Регистрация выполняется только по нажатию кнопки, для текущего пользователя. Если переместили приложение, повторно добавьте пункт меню из нового расположения. Перед удалением папки приложения удалите пункт меню в настройках; заметки при этом сохраняются.

Приложение работает в трее с одним общим значком. Двойной клик по значку создаёт заметку. В меню доступны создание, «Показать все» (включая скрытые заметки), настройки, повторное сохранение при ошибке и выход. Отдельного списка заметок в трее нет. Стикеры не отображаются на панели задач и в Alt+Tab; второй запуск показывает существующие заметки, `DesktopNotes.exe --new-note` создаёт новую.

## Стикер

- Отдельного заголовка над текстом нет. Новая заметка начинается с `# Новая заметка` и пустой строки; название редактируется прямо в тексте как H1. Перетаскивайте за узкий свободный верхний отступ, в свёрнутом виде — за название. Размер меняется за края и углы.
- Название свёрнутого стикера берётся из первого непустого H1 верхнего уровня (также поддерживается подчёркивание `===`), без маркеров форматирования. Изменение H1 и Undo сразу обновляют имя, включая внутренние ссылки по названию. После удаления H1 показывается «Без названия». При загрузке старых заметок без H1 сохраняется прежнее имя; текст автоматически не переписывается.
- `−` в правом верхнем углу сворачивает до полоски заголовка и восстанавливает прежнюю высоту. Минимальный развёрнутый размер — 220 × 140, начальный — 320 × 280 единиц WPF.
- Правый клик в любом месте стикера открывает расположение окон, действия группы и связей, скрытие и удаление с подтверждением. Скрытые заметки восстанавливаются общей командой «Показать все» в трее.
- Клик по стикеру показывает панель над ним: шесть цветов заметки, размер шрифта 8–72, жирность, выравнивание слева/по центру/справа/по ширине и сверху/по середине/снизу, закрепление положения. Размер и выравнивание применяются ко всему тексту и сохраняются отдельно от Markdown. Кнопка B при выделении текста добавляет или снимает **жирное оформление** только выбранного фрагмента; без выделения переключает жирность всей заметки. Подсказки при наведении отключены. Заголовки и код сохраняют относительные размеры. Длинный текст прокручивается. Панель следует за стикером; у верхней границы экрана появляется снизу. Сворачивание или снятие выбора скрывают её.
- Единый редактор **Live Preview** заменяет переключение редактирования и просмотра. Текст постоянно остаётся редактируемым и оформленным: перемещение курсора, выделение и снятие фокуса не заменяют строки другим представлением. Ввод `- ` сразу показывает круглый маркер с небольшим отступом; нумерация и задачи также оформляются прямо при вводе. Разметка хранится в документе, а визуальные маркеры не меняют его содержимое. Одиночные переводы строк остаются видимыми, в том числе после Shift+Enter внутри пункта списка; перевод строки не заменяется пробелом. Внутренние поля редактора — 6 единиц WPF, внешние отступы развёрнутого стикера — 7,5 единицы WPF (увеличены на 50%); отдельная пустая полоса над H1 убрана. Справа зарезервировано место для кнопки сворачивания. Отступ списка — 16 без дополнительного внешнего сдвига; лишние промежутки между строками убраны. При переполнении появляется тонкая вертикальная полоса прокрутки в оттенке заметки; колесо мыши и клавиатура продолжают работать. Enter и Shift+Enter сразу прокручивают новую строку в видимую область. HTML отображается текстом; изображения и вложения не загружаются.
- «Поверх окон» использует обычный Windows topmost: системные защищённые экраны и другие topmost-окна могут находиться выше.
- «На задний план» опускает заметку при выборе режима и потере фокуса. При клике её можно поднять для редактирования. Это обычное окно: Win+D может скрыть его вместе с другими окнами.

Автозапуск выключен. Переключатель автозапуска пока не предусмотрен.

## Редактирование Markdown

Переносы отображаются как в [Obsidian с выключенными Strict line breaks](https://obsidian.md/help/settings): не требуется добавлять два пробела или HTML для сохранения новой строки.

Поддерживаются заголовки, жирный и курсивный текст, зачёркивание `~~текст~~`, маркер `==текст==`, списки, задачи, цитаты, встроенный и блочный код, таблицы и веб-ссылки. Оформление доступно также в ПКМ → «Оформление текста». Markdown сохраняется как исходный текст; переход между блоками не переписывает его. Разметка заголовков и завершённого встроенного оформления скрывается визуальными элементами, не раскрывается при переходе курсора и не меняет геометрию текста. Таблицы редактируются в строках с общими границами колонок; Tab перемещает между ячейками. В списке Tab/Shift+Tab меняют отступ пункта, Home переходит к началу текста, Backspace в начале убирает маркер целиком. Автоматически перенесённые строки выравниваются по тексту пункта. Выравнивание также остаётся одинаковым при редактировании и снятии фокуса; таблицы сохраняют общую сетку колонок. Блочный код отображается в общей закруглённой рамке с фоном и внутренним отступом, без фона под каждым символом. Ограждения скрыты визуально, но остаются в исходном Markdown и копируются вместе с выделением. Ввод трёх обратных кавычек (также с именем языка) и Enter создаёт закрытый блок одним действием Undo и ставит курсор внутри; Shift+Enter по-прежнему вставляет только перевод строки. Backspace в начале первой строки содержимого снимает блок кода: оба ограждения и рамка исчезают, содержимое и его переводы строк остаются; Undo восстанавливает блок одним действием. Работает и для пустого или незакрытого блока. Код сохраняет моноширинное обычное начертание независимо от жирности всей заметки.

Заголовки создаются вводом `# ` … `###### `, как в [Markdown Obsidian](https://obsidian.md/help/syntax). У H1–H6 отдельные относительные размеры и начертания; оформление появляется после пробела и не меняется при выделении или потере фокуса. Ctrl+1…6 меняет уровень текущей/выделенных строк; повторное нажатие снимает тот же уровень. ПКМ → «Оформление текста → Заголовок» позволяет выбрать H1–H6 или обычный текст. Home переходит к началу текста заголовка, Backspace там убирает префикс целиком. Пустые строки внутри выделенного фрагмента сохраняются. Поддерживаются заголовки с табуляцией после `#`, в цитатах/списках и с необязательными завершающими `#`; код и экранированные символы не превращаются в заголовки.

Выделение использует ровную полупрозрачную подсветку без обводки и без служебных обозначений пробелов, табуляции, концов строк и управляющих символов. Эти изменения касаются только отображения: пустые строки сохраняются, выделяются, копируются и удаляются как часть исходного Markdown.

| Клавиши | Действие |
| --- | --- |

Основные сочетания навигации и редактирования сверены с [официальной справкой Obsidian](https://obsidian.md/help/editing-shortcuts). Ctrl+L для задач и Ctrl+Enter для ссылок соответствуют [назначениям Obsidian](https://obsidian.md/changelog/2022-10-13-desktop-v1.0.0/). Прежний Ctrl+Enter для создания задачи заменён на Ctrl+L. Ctrl+W скрывает стикер, сохраняя его данные; вернуть его можно через «Показать все» в трее. Сочетания действуют в окне заметки, включая русскую раскладку; это не глобальные клавиши Windows.

Скобки и кавычки вводятся парами и могут окружать выделение. Клик по флажку задачи в оформленном блоке обновляет `[ ]` / `[x]` с возможностью отмены.

**Внутренние ссылки:** ПКМ → «Вставить ссылку на заметку» вставляет `[[идентификатор|название]]`. Такая ссылка сохраняется при переименовании целевой заметки. Можно вручную написать `[[Название]]` или `[[Название|Подпись]]`; при одинаковых названиях выбирается первая подходящая заметка. Ctrl-клик по оформленной ссылке открывает цель, включая скрытую заметку. Обычный клик ставит курсор в подпись ссылки; источник остаётся Markdown, Ctrl+K вставляет веб-ссылку. Несуществующая цель вызывает сообщение; новая заметка автоматически не создаётся. Ctrl-клик по веб-ссылке открывает браузер.

Редактор реализован для DesktopNotes на AvalonEdit и Markdig. Хранилища, плагины, вложения и изображения Obsidian не добавлены. Уведомления о лицензиях зависимостей находятся в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) и входят в сборку.
## Группы, прилипание и связи

**Прилипание.** При перемещении за заголовок соседние края и углы стикеров притягиваются в пределах 3 единиц WPF (3 пикселей при масштабе 100%). Во внешней части этой зоны поправка уменьшена вдвое; точное совмещение выполняется только в пределах 1 единицы WPF. При выходе за радиус заметка сразу следует за мышью без удержания. У расположенных рядом заметок выравниваются верхние или нижние углы, у расположенных друг над другом — левые или правые: так можно собрать ровный вертикальный столбец. Выравнивание работает и при уже соприкасающихся краях, и при разных размерах заметок. Диагонально расположенные углы также притягиваются, если зазор по каждой оси не превышает порог. Далеко расположенные стикеры не притягиваются. Потяните дальше, чтобы разъединить стикеры. Прилипание само по себе не создаёт группу. Для группы проверяются края всех видимых участников, а найденная поправка применяется ко всей группе без изменения расстояний между участниками.

**Новая группа.** Зажмите Ctrl и кликните по двум или более свободным заметкам. Черновой выбор подсвечивается оранжевой рамкой. Повторный Ctrl-клик исключает заметку из выбора. Кликните без Ctrl в любом месте экрана: группа сформируется, а её заметки получат одинаковую рамку собственного цвета. Клик по стикеру без Ctrl также завершает выбор до обычного действия. Escape на стикере отменяет незавершённый выбор.

**Изменение группы.** Ctrl-клик по любому её участнику выбирает существующую группу. Последующие Ctrl-клики по свободным заметкам добавляют их; по выбранным участникам — исключают. Клик без Ctrl фиксирует результат. Чтобы исключить первый выбранный участник, кликните по нему с Ctrl ещё раз. Можно сначала выбрать свободные заметки, затем Ctrl-кликнуть по существующей группе. Перенос заметки из другой группы требует сначала исключить её из прежней; автоматического слияния разных групп нет. Группа распускается, если осталось меньше двух участников.

Перетаскивание за заголовок любого участника перемещает всю группу, включая скрытых участников, сохраняя их относительное положение. ПКМ по участнику → «Цвет рамки группы…» задаёт произвольный цвет; «Распустить группу» оставляет заметки на местах. Цвет каждой группы сохраняется независимо.

**Закрепление.** Кнопка замка на панели над редактируемой заметкой запрещает её перетаскивание. Повторное нажатие снимает закрепление. Если закреплён хотя бы один участник, вся группа не перемещается; курсор над её заголовками показывает запрет. Редактирование, смена размера, создание связей и удаление из группы остаются доступны. При отключении монитора система по-прежнему возвращает недоступные стикеры на видимый экран.

**Стрелки.** Кликните по стикеру: появляется тонкая голубая рамка и четыре небольшие голубые точки снаружи, напротив середины сторон. Alt не требуется. При наведении точка превращается в стрелку наружу. Зажмите точку/стрелку левой кнопкой и потяните к другой заметке. При приближении к цели на 18 единиц WPF конец притягивается к её краю, а целевой стикер показывает рамку и четыре точки присоединения на сторонах. Отпустите кнопку для создания связи. Отпускание на пустом месте, над другим приложением, потеря захвата или Escape отменяет создание. Клик по другой заметке переносит выбор; Escape или переход в другое окно убирает точки. Жест работает также на свёрнутой и закреплённой заметке. Ctrl-клик сохраняет работу с группами. Повторная связь в том же направлении не дублируется; обратная связь разрешена.

Оба конца стрелки автоматически переходят к ближайшей паре сторон при движении и изменении размеров заметок. При перетаскивании предварительная линия также меняет сторону вслед за курсором. Это применяется и к ранее созданным связям; сохранённое поле SourceSide читается для совместимости, но больше не фиксирует положение связи.

Стрелки соединяют края заметок горизонтальными и вертикальными участками со скруглёнными поворотами. Положение обновляется при перемещении, изменении размера и сворачивании. У соприкасающихся/перекрывающихся стикеров линия проходит снаружи, чтобы оставаться видимой. Если один конец скрыт или минимизирован, стрелка скрывается. Линия располагается позади обоих стикеров. Наведение слегка подсвечивает её, клик выделяет белыми кружками с голубой обводкой на концах; сама линия остаётся серой. Delete удаляет выбранную связь, Escape или переход к другому окну снимает выделение. Клики принимаются в узкой зоне вдоль линии и наконечника; остальная площадь прозрачного окна пропускает их. При редактировании заметки Delete продолжает удалять текст. Связь также можно удалить через ПКМ по любой из связанных заметок → «Удалить связь»; удаление самой заметки автоматически удаляет её связи. Изменение формы перетаскиванием пока не предусмотрено.

Стандартное оформление соответствует предоставленным примерам: спокойная серая линия толщиной 2 единицы WPF, скруглённые повороты и компактный серый наконечник. Прежние стандартные связи получают то же оформление; явно заданные цвет, толщина и тип линии сохраняются. Формат хранения остаётся версией 2.

Для будущей настройки стрелок введены отдельные `NoteLink` и `LinkStyle`: ширина, цвет, тип линии и прямой/кривой маршрут. Сервис и renderer поддерживают эти поля; UI настройки стрелок пока не добавлен.

## Журнал и диагностика

Журнал включён автоматически: `%LocalAppData%\DesktopNotes\logs\DesktopNotes-*.log`. Если задан `DESKTOPNOTES_DATA_DIR`, папка `logs` создаётся внутри неё. В настройках есть кнопка «Открыть папку журналов». Каждый процесс получает свой файл; запись выполняется сразу, включая время UTC, уровень, идентификаторы процесса и потока, событие и стек исключения.

Записываются версия сборки, запуск, загрузка и сохранение, восстановление из копии, передача команды другому экземпляру, создание окон, ошибки UI и фоновых задач, выход. Названия и Markdown заметок специально в журнал не записываются. Диагностика содержит локальные пути и сообщения исключений. При достижении примерно 2 МБ файл ротируется; сохраняются до 10 последних файлов. Отказ записи журнала не вызывает падение приложения.

Исправлен сбой Live Preview после многострочного списка с последующей пустой строкой: завершающий перевод строки попадал в оформленный блок и захватывал следующую несвёрнутую строку AvalonEdit. Сохранённый список вызывал ту же ошибку при запуске. Исправление меняет только границы отображения, исходный Markdown сохраняется. При повторной ошибке этого типа во время работы приложение записывает её и временно отключает Live Preview до перезапуска, оставляя исходный текст доступным для редактирования. Остальные необработанные ошибки показываются с путём к журналу и завершают приложение; последние изменения, ещё ожидающие автосохранения, могут быть потеряны.

При обращении по поводу сбоя приложите самый свежий `.log` из этой папки. Не удаляйте файл заметок для исправления ошибки отображения: обновлённая сборка открывает прежние данные.
## Данные и архитектура

Данные: `%LocalAppData%\DesktopNotes\notes.json`, резервная копия: `notes.json.bak`. Автосохранение через 500 мс после изменения; выход через трей ожидает запись. При ошибке запись можно повторить из трея; выход отменяется, чтобы оставить изменения в памяти. Принудительное завершение процесса может потерять последние изменения. Резервная копия содержит предыдущую успешную версию; после первой записи — начальную.

Если основной файл повреждён, загружается копия с уведомлением. Если повреждены оба файла либо формат создан более новой версией приложения, запуск прекращается без перезаписи файлов. Положение окон корректируется при запуске, показе скрытого окна и изменении конфигурации мониторов. Настройки скрытия, сворачивания, закрепления, расположения, состав и цвет групп, а также связи сохраняются.

Формат хранения — версия 2. Заметки версии 1 загружаются с пустыми группами и связями; при первой записи создаётся версия 2, а предыдущий файл остаётся резервной копией. После обновления используйте новую версию приложения: старые сборки не поддерживают формат 2.

- `Domain`: модели `Note`, `NoteGroup`, `NoteLink`, `LinkStyle`, `WorkspaceSnapshot`, проверка ссылочной целостности; без UI и внешних сервисов.
- `Application`: `NoteService`, транзакции состава групп и связей, `GroupSelectionSession`, чистые алгоритмы `SnapCalculator`/`ArrowRouter`, `AutosaveCoordinator`, интерфейсы хранения и Windows-адаптеров.
- `Infrastructure`: JSON с версией формата и атомарной заменой, реестр, Win32, mutex и named pipe с доступом текущего пользователя.
- `Presentation`: ViewModel, окна WPF, `BoardInteractionController` для жестов, `ArrowOverlay` для прозрачных стрелок, AvalonEdit + Markdig → визуальные элементы строк для редактирования без смены представления; отдельные InlineMarkdownLayout, MarkdownDecorationElement и InlineMarkdownMetrics отвечают за разбор, отображение маркеров и измерения, трей. DI собирается в `NotesApp.OnStartup`.

Мутации `NoteService` и вызовы `AutosaveCoordinator` выполняются на UI-потоке. Записи всего рабочего пространства сериализуются; ViewModel не знает о JSON и Win32. Ctrl-выбор хранится как черновик до завершения. Наблюдатель глобального клика включается только на время такого выбора, не перехватывает и не записывает ввод. Windows-координаты при движении и отрисовке используются в физических пикселях с учётом DPI; положение окон сохраняется в единицах WPF.

## Сборка и проверки

Нужны Windows, .NET SDK 10 и доступ к NuGet. Из корня проекта:

```powershell
./scripts/build.ps1
```

Скрипт восстанавливает зависимости, собирает Release, запускает тесты и обновляет единственную автономную сборку `artifacts/win-x64` и архив `artifacts/DesktopNotes-win-x64.zip`. Папки отдельных версий не создаются; история исходников хранится в Git. Перед обновлением закройте приложение через трей: скрипт не перезаписывает исполняемые файлы запущенной сборки. Отдельно:

```powershell
dotnet restore DesktopNotes.slnx --configfile NuGet.Config
dotnet build DesktopNotes.slnx -c Release --no-restore
dotnet test DesktopNotes.slnx -c Release --no-build --no-restore
```

Для изолированной проверки интерфейса задайте `DESKTOPNOTES_DATA_DIR` абсолютным путём к тестовой папке перед запуском. Такая папка имеет отдельный идентификатор экземпляра и не затрагивает обычные заметки. Это диагностическая настройка, не синхронизация.

Ручная приёмка описана в [docs/acceptance.md](docs/acceptance.md). Совместимость с Windows 10 22H2 требует проверки на соответствующей машине; успешная сборка на Windows 11 не заменяет эту проверку. Официальная поддержка .NET зависит от редакции и жизненного цикла Windows.

Предпросмотр связи обновляется один раз на кадр WPF, без конкурирующих обновлений по таймеру и MouseMove. На время перетаскивания прозрачная область предпросмотра остаётся фиксированной на виртуальном рабочем столе; перемещается сама линия, а не её окно. Повторная отрисовка одинаковой геометрии пропускается, подсветка цели обновляется только при её смене. Подписка на кадры снимается при завершении, отмене и выходе.

## Оптимизация редактора и сохранения

Измерения текста и ширины колонок таблиц кэшируются до изменения Markdown или параметров шрифта; поиск скрытой разметки и стилей ограничен пересекающимися диапазонами. Панель реагирует только на нужные параметры оформления, сохраняя незавершённый ввод размера шрифта при редактировании текста и движении стикера.

Сериализация, принудительная запись и атомарная замена JSON выполняются в фоне. Снимок состояния создаётся на UI-потоке, записи по-прежнему выполняются последовательно, уведомления возвращаются в исходный контекст интерфейса. При завершении сеанса Windows сохраняются текущие границы окон и сформированные группы; сеанс отменяется, если запись не удалась.

Первая строка стикера всегда остаётся заголовком H1: удаление всего названия оставляет пустой заголовок для нового ввода. Между ним и содержимым предусмотрен небольшой отступ. При открытии заметки без заголовка её первая строка становится H1; текст сохраняется. Остальные строки поддерживают обычные уровни заголовков Markdown.
