Подчёркивание и исправление наложения выделения текста.

- Добавлено подчёркивание: Ctrl+U или ПКМ → «Оформление текста» → «Подчёркнутый», разметка `++текст++`.
- Подчёркивание сочетается с другими стилями и снимается независимо от них; поддерживается Undo.
- Синий фон выделения мышью или Shift отображается поверх жёлтого маркера и фона встроенного кода. Текст остаётся чётким; после снятия выделения исходный фон восстанавливается.
- Проверены все 720 порядков применения шести встроенных стилей и отрисовка в светлой/тёмной темах. Прошли 347 тестов.

### Скачать и обновить

Скачайте **DesktopNotes-Setup.exe**, закройте приложение через трей → «Выход» и запустите установщик. Заметки и настройки сохранятся. .NET включён; права администратора не нужны. **DesktopNotes-win-x64.zip** — запуск без установки, **SHA256SUMS.txt** — контрольные суммы.

Windows 10 22H2 / Windows 11, x64; Windows 10 требует отдельной проверки. Приложение пока не подписано цифровым сертификатом, поэтому Windows может показать предупреждение SmartScreen.

### English

Underline is available via Ctrl+U or the text formatting menu (`++text++`). It composes with all existing styles. Mouse/Shift selection now appears above highlights and inline-code backgrounds. Close the app from the tray before upgrading. Notes and settings are preserved.
