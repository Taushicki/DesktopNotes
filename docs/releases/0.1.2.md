Исправлена точка создания связи, перекрывавшая кнопки панели форматирования.

- Точки связи располагаются за пределами панели; у края экрана точка остаётся доступной сбоку от панели.
- Панель находится выше окон точек связи и принимает нажатия без помех.
- Убран стандартный синий квадрат при наведении на точку связи: вместо него используется мягкий круглый ореол.
- Выбранная стрелка подсвечивается вдоль своего контура, без прямоугольной рамки.
- Проверены разные DPI и размещение панели над/под заметкой; прошли все 344 теста.

### Скачать и обновить

Скачайте **DesktopNotes-Setup.exe**, закройте приложение через трей → «Выход» и запустите установщик. Заметки и настройки сохранятся. .NET включён; права администратора не нужны. **DesktopNotes-win-x64.zip** — запуск без установки, **SHA256SUMS.txt** — контрольные суммы.

Windows 10 22H2 / Windows 11, x64; Windows 10 требует отдельной проверки. Приложение пока не подписано цифровым сертификатом, поэтому Windows может показать предупреждение SmartScreen.

### English

Connection ports no longer cover formatting toolbar buttons. Ports avoid the toolbar and stay accessible near screen edges. A subtle circular hover replaces the blue square; selected connections receive a soft outline. Close the app from the tray before upgrading. Notes and settings are preserved.
