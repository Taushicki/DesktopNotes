Исправления совместного форматирования текста.

- Жирный, курсив, зачёркивание, маркер и встроенный код сочетаются на одном фрагменте в любом порядке.
- Снятие одного стиля сохраняет остальные; форматирование части фрагмента сохраняет стиль соседнего текста.
- Ссылки одновременно отображают подчёркивание и зачёркивание. Маркер остаётся видимым при сочетании со встроенным кодом.
- Выделение и Undo сохранены. Комбинации проверены во всех 120 порядках применения пяти стилей; всего прошли 338 тестов.

### Скачать и обновить

Скачайте **DesktopNotes-Setup.exe**, закройте приложение через трей → «Выход» и запустите установщик. Заметки и настройки сохранятся. .NET включён; права администратора не нужны. **DesktopNotes-win-x64.zip** — запуск без установки, **SHA256SUMS.txt** — контрольные суммы.

Windows 10 22H2 / Windows 11, x64; Windows 10 требует отдельной проверки. Приложение пока не подписано цифровым сертификатом, поэтому Windows может показать предупреждение SmartScreen.

### English

Fixes combined Markdown formatting: bold, italic, strike, highlight and inline code can be applied together in any order. Removing one style preserves the others. Links retain underline and strike simultaneously. Close the app from the tray before upgrading with **DesktopNotes-Setup.exe**. Notes and settings are preserved.
