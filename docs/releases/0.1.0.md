Первый публичный релиз DesktopNotes — стикеры с Markdown для Windows.

### Скачать

- **[DesktopNotes-Setup.exe](https://github.com/Taushicki/DesktopNotes/releases/download/v0.1.0/DesktopNotes-Setup.exe)** — установщик. Скачайте и запустите: .NET уже включён, права администратора не нужны. Появится ярлык в меню «Пуск»; ярлык на рабочем столе можно выбрать при установке.
- **[DesktopNotes-win-x64.zip](https://github.com/Taushicki/DesktopNotes/releases/download/v0.1.0/DesktopNotes-win-x64.zip)** — запуск без установки. Распакуйте архив целиком в постоянную папку и запустите `DesktopNotes.exe`.
- **SHA256SUMS.txt** — контрольные суммы загрузок.

Windows 10 22H2 / Windows 11, x64. Совместимость с Windows 10 требует отдельной проверки на этой ОС.

### Возможности

Markdown Live Preview, заголовки, списки, блоки кода и таблицы; светлые и тёмные темы; перемещение и сворачивание заметок; прилипание, группы и стрелки; панель форматирования; меню рабочего стола и трея; локальное автосохранение; русский и английский интерфейс; настраиваемое логирование.

### Установка и обновление

Перед обновлением закройте DesktopNotes через трей → «Выход». При первом запуске пункт меню рабочего стола можно добавить в настройках; в Windows 11 он находится в «Показать дополнительные параметры».

Заметки и настройки сохраняются в `%LocalAppData%\DesktopNotes`. Обновление и удаление приложения не удаляют эти данные. Автозапуск по умолчанию выключен.

Установщик и приложение пока не подписаны цифровым сертификатом: Windows может показать предупреждение SmartScreen. Используйте загрузки из этого репозитория.

### English

Download **DesktopNotes-Setup.exe** to install, or extract **DesktopNotes-win-x64.zip** for portable use. Windows x64; .NET is included, no administrator privileges are required. Close the app from the tray before upgrading. Uninstalling preserves notes and settings. The app is currently unsigned. Choose English in Settings → Interface.
